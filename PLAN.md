# План разработки лендинга

Источник требований — [спецификация лендинга](https://claude.ai/artifact/CarK6cUn9DpKEq89PRLymm).

## Принятые решения

| Вопрос | Решение |
|--------|---------|
| Стек | Django + шаблоны + vanilla JS (не статика на GitHub Pages, не DRF) |
| Дизайн-токены | Значения из спецификации; `DESIGN.md` обновляется под них и остаётся единственным источником правды |
| Данные комплектов | Модель `Kit` в Django-админке, без правки кода при добавлении |
| Заявки | Сохраняются в БД (`Lead`), видны в админке |

## Этапы

### 0. Синхронизировать `DESIGN.md` со спецификацией

- [x] Шрифты: Unbounded (400) для заголовков, Onest для текста; размеры H1–H3 и текста из спецификации
- [x] Цвета: `--color-sage`, `--color-white`, `--color-mint`, `--color-carbon`, `--color-forest`, `--color-slate`, `--color-mist` (`#5F6B6C`), `--color-teal` (только заливка главной кнопки)
- [x] Форма и отступы: радиусы 36 / 20 / 16 / 12px, шаг 4px, контент 1200px, теней нет
- [x] Компоненты: кнопки трёх видов, слайдер, форма, модалки
- [ ] Закрыть открытые вопросы в `DESIGN.md` (контраст надзаголовка, фокус, цвет ошибки и др.)

### 1. Основа шаблонов и статики

- [ ] `base.html`: `lang="ru"`, title, description, Open Graph, фавиконы
- [ ] Google Fonts с `display=swap`
- [ ] `static/css/`: `tokens.css`, `base.css`, `components.css`
- [ ] `static/js/`, `static/img/`

### 2. Модели и админка (`apps/main`)

- [ ] `Kit` — модель авто, тип защиты, метка, три строки характеристик, фото, порядок, активность; карточка «Ваша модель» — запись с отдельным флагом
- [ ] `Lead` — имя, телефон, модель авто, дата, статус, источник
- [ ] `SiteSettings` — синглтон: телефон, почта, ВКонтакте, адрес, срок ответа на заявку
- [ ] Админка на `TimestampedAdminMixin` и `SingleObjectAdminMixin`
- [ ] Данные для примера: JAC T9 и Haval H3, передняя и задняя защита

### 3. Статичная вёрстка девяти блоков

- [ ] Каждый блок — partial в `templates/main/sections/`
- [ ] Якоря: `about`, `products`, `benefits`, `custom`, `contacts`
- [ ] Комплекты и контакты из БД, остальные тексты — заглушки в квадратных скобках

### 4. Форма заявки

- [ ] Django-форма: имя и телефон обязательны, телефон в формате +7
- [ ] Отправка POST через `fetch` с CSRF-токеном, ответ JSON с ошибками по полям
- [ ] Сохранение в `Lead`, блокировка повторного нажатия во время отправки

### 5. Интерактив на чистом JS

- [ ] `slider.js` — стрелки, клик по соседней карточке, свайп, клавиатура, цикл, счётчик
- [ ] `scramble.js` — подбор букв
- [ ] `modal.js` — загрузка, успех, ошибка; удержание фокуса, закрытие по Esc
- [ ] `form.js` — маска телефона и отправка
- [ ] Поддержка `prefers-reduced-motion`

### 6. Адаптив и доступность

- [ ] Ширины 320–1920px, точки перестройки 768 и 1024px, бургер-меню
- [ ] WCAG 2.1 AA: контраст, зона нажатия 44px, видимый фокус, ARIA для карусели

### 7. Уведомления о заявке

- [ ] Для разработки — вывод в консоль
- [ ] Рабочий канал (почта или Telegram) — после ответа заказчика
- [ ] Способ отправки: Celery (как в `tiredepo-auto-parts`) или сигнал Django

### 8. Производительность и SEO

- [ ] WebP + `srcset`, `loading="lazy"` ниже первого экрана, главное фото до 200 КБ
- [ ] Lighthouse (мобильный): Performance ≥ 90, Accessibility ≥ 95, SEO ≥ 90

### 9. Деплой

- [ ] gunicorn + whitenoise, Postgres, настройки из `.env`
- [ ] README с инструкцией запуска
